# Security

This repository publishes documentation and release artifacts for a
simulation-only material candidate.

## Report Privately

If you believe the repository contains:

- secrets
- private infrastructure details
- unintended internal release artifacts
- sensitive data that should not be published

please report it privately to the maintainers instead of opening a public
issue.

## Scope Note

This repository is not a production software service. Most relevant security
issues here are release-scope or disclosure issues, not live system exploits.
